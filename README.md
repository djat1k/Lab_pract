🚀 Быстрый старт

Клонировать репозиторий:

git clone https://github.com/djat1k/Lab_pract.git
git checkout lab9


Установить зависимости:

npm install


Запустить проект:

npm run dev


Открыть в браузере:
Перейти по адресу, который покажет командная строка (обычно http://localhost:5173).
