# ToDo Приложение на React

Минимальное приложение для управления списком задач, созданное с использованием React и функциональных компонентов.

## Описание

Это простое ToDo-приложение позволяет пользователям:
- Добавлять новые задачи
- Просматривать список всех задач
- Удалять отдельные задачи
- Очищать весь список задач одним кликом
- Автоматически сохранять задачи в браузере (localStorage)

## Технологии

- **React 19.2.0** - библиотека для создания пользовательских интерфейсов
- **Vite** - инструмент сборки и разработки
- **JavaScript (JSX)** - язык программирования
- **CSS** - стилизация компонентов

## Структура проекта

```
src/

├── AddTaskForm.jsx   # Форма для добавления задач

├── ToDoItem.jsx      # Компонент отдельной задачи
├── App.css           # Стили приложения
├── index.css         # Глобальные стили
└── main.jsx          # Точка входа приложения
```

## Компоненты

### App.jsx
Главный компонент приложения, который:
- Управляет состоянием списка задач с помощью `useState`
- Сохраняет и загружает задачи из `localStorage` с помощью `useEffect`
- Содержит функции `addTask`, `removeTask` и `clearAllTasks`
- Рендерит форму добавления задач и список задач

### AddTaskForm.jsx
Компонент формы для добавления новых задач:
- Содержит `<input>` для ввода текста задачи
- Имеет кнопку "Добавить" для отправки формы
- Получает функцию `addTask` через пропсы
- Использует локальное состояние для управления значением input

### ToDoList.jsx
Компонент списка задач:
- Получает массив `tasks` и функцию `removeTask` через пропсы
- Рендерит список элементов `ToDoItem` для каждой задачи
- Использует метод `map` для отображения всех задач

### ToDoItem.jsx
Компонент отдельной задачи:
- Отображает текст задачи
- Содержит кнопку "Удалить" для удаления задачи
- Получает объект `task` и функцию `removeTask` через пропсы

## Функциональность

### Сохранение в localStorage
Приложение автоматически сохраняет все задачи в `localStorage` браузера. Это означает, что:
- Задачи сохраняются между сеансами работы
- При перезагрузке страницы все задачи остаются на месте
- Данные хранятся локально в браузере пользователя

### Управление задачами
- **Добавление**: Введите текст задачи в поле ввода и нажмите "Добавить" или Enter
- **Удаление**: Нажмите кнопку "Удалить" рядом с нужной задачей
- **Очистка**: Нажмите кнопку "Очистить всё" для удаления всех задач (с подтверждением)

## Установка и запуск

1. Установите зависимости:
```bash
npm install
```

2. Запустите сервер разработки:
```bash
npm run dev
```

3. Откройте браузер и перейдите по адресу, указанному в терминале (обычно `http://localhost:5173`)

## Сборка для production

Для создания production-сборки выполните:
```bash
npm run build
```

Собранные файлы будут находиться в папке `dist`.

## Особенности реализации

- Использование функциональных компонентов React
- Хук `useState` для управления состоянием
- Хук `useEffect` для работы с localStorage
- Передача данных и функций через пропсы (props)
- Односторонний поток данных (data flows down, events flow up)
- Иммутабельные обновления состояния
- Адаптивный дизайн с поддержкой светлой и тёмной темы
