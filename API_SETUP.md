# Настройка API для каталога фильмов

## Быстрая инструкция (2 минуты):

1. **Перейдите на** https://www.themoviedb.org/signup
2. **Зарегистрируйтесь** (бесплатно, только email)
3. **Перейдите в** https://www.themoviedb.org/settings/api
4. **Нажмите "Request API Key"**
5. **Выберите "Developer"** и заполните форму
6. **Скопируйте ваш API ключ**

## Установка ключа:

### Вариант 1: Прямо в коде
Откройте `src/App.jsx` и замените:
```javascript
const API_KEY = 'ваш_ключ_здесь'
```
на:
```javascript
const API_KEY = 'ваш_реальный_ключ'
```

### Вариант 2: Через переменную окружения (рекомендуется)
Создайте файл `.env` в корне проекта:
```
VITE_TMDB_API_KEY=ваш_реальный_ключ
```

И в `src/App.jsx` уже настроено автоматическое чтение из `.env`

## После установки:
1. Сохраните файл
2. Обновите страницу в браузере (F5)
3. Готово! Поиск фильмов будет работать

---

**Примечание:** TMDB API полностью бесплатный, предоставляет 1000+ запросов в день и не требует оплаты.
